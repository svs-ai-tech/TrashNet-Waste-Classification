# ♻️ TrashNet Waste Classification

> Automated garbage sorting using Deep Learning (CNN) and Streamlit.

---

### 📊 Project Highlights
* **Dataset:** TrashNet (2,527 images)
* **Model:** Custom 3-Block CNN with Data Augmentation
* **Validation Accuracy:** ~67%
* **Classes:** Cardboard, Glass, Metal, Paper, Plastic, Trash

---

### 🚀 Tech Stack
* **Deep Learning:** TensorFlow & Keras
* **Deployment:** Streamlit Web Interface
* **Environment:** Google Colab

---

### 💻 How to Run Locally
```bash
pip install streamlit tensorflow pillow numpy
streamlit run app.py
